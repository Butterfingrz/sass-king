# Documentation

This directory contains navigation and process documentation. It is not the primary place for SASS evidence; evidence starts in `corpus/`, is consolidated in `knowledge/`, and is formalized into reusable signatures in `patterns/`.

| File | Purpose |
|---|---|
| `START_HERE.md` | Shortest reader path through the project. |
| `PROJECT_STRUCTURE.md` | Repository layout, content ownership, and reader paths. |

Use this directory when you need to understand how to move through the repository. Use `knowledge/` when you need the technical source of truth.
