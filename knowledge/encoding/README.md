# Encoding Notes

This directory contains instruction-family encoding notes and bit-level cross-check material. These pages support the semantic findings in `knowledge/FINDINGS.md`; they do not replace local dump evidence.

| File | Purpose |
|---|---|
| `schema.md` | Shared page format for encoding notes. |
| `CONTROL_CODE.md` | Control-code field notes and remaining stall/yield gaps. |
| `LDSM.md` | Matrix-load encoding notes. |
| `STSM.md` | Matrix-store encoding notes. |
| `QMMA.md` | Blackwell dense, sparse, and scaled QMMA encoding notes. |

Use these pages when a pattern or finding needs low-level field support. Keep observations tied to local dumps, denvdis output, or other explicitly cited evidence.
